Documentation / Quickstart

Build your first scene.

Draw an explorer, move it with the keyboard and collect a relic. You’ll learn how Dino GE represents game objects and where to put your game logic.

You’ll need basic JavaScript and a browser. Allow about 20 minutes, including time to try the exercises.

Browse the API reference

1. Install the engine

In an existing JavaScript or TypeScript project with a browser bundler, install the beta package.

npm install dino-ge@beta

2. Add a game object

Add <div id="first-scene"></div> to your page. Give it a height, then add this to your module entry point. The engine runs onLoad when it is ready to create game objects.

import { Circle, Engine, Vector2 } from "dino-ge";

new Engine({
  onLoad: () => {
    new Circle({
      position: new Vector2(96, 96),
      radius: 28,
      colour: "#ffc46f"
    });
  },
  update() {}
}, {
  title: "Quickstart | Dino GE",
  width: "100%",
  height: "100%",
  containerId: "first-scene"
});

A scene contains game objects. Components give those objects data such as position and appearance. Systems use that data to render the scene or simulate physics. The circle above already has a transform for position and a shape for rendering.

Try it. Change the radius from 28 to 14 and the first coordinate from 96 to 42. The circle should shrink and move left. The second coordinate increases downwards.

3. Move the explorer

Give the circle a tag of "explorer" so it’s easy to identify. Declare let player before creating the engine, and assign your circle to it in onLoad. Add Input to your imports and put the movement code in fixedUpdate.

fixedUpdate() {
  const right = Number(Input.isKeyDown("ArrowRight"));
  const left = Number(Input.isKeyDown("ArrowLeft"));
  player.transform.position.x += (right - left) * 2;
}

onLoad sets up the game once. fixedUpdate runs on regular simulation steps, so this movement advances by the same amount on each step. update runs on each rendered frame and can handle visual changes.

Try it. Add up and down movement using position.y. Press both horizontal keys together and check that the explorer stays still.

4. Collect a relic

Create a second circle in onLoad and keep a reference to it as relic. After moving the player, compare the distance between the circles to the sum of their radii. For an explorer with radius 14 and a relic with radius 10, they touch at 24 pixels.

if (relic && Vector2.distance(
  player.transform.position, relic.transform.position
) <= 24) {
  Engine.destroyObject(relic);
  relic = undefined;
}

The distance check is enough for this pickup. Use a PhysicsComponent when you want the engine to simulate motion and resolve collisions.

Tab to the game or click it, then hold the right arrow to collect the relic. Reset the scene to try again.

Download the finished JavaScript and its companion HTML. To run the pair in your own bundled project, put them in the same folder, point the module script at ./collect-a-relic.js and let the bundler resolve dino-ge instead of using the demo’s import map.

Try it. Move the relic to a different starting position. Then add a second relic and keep score as each is collected.

5. Read a complete game

Open Amber Ruins in the Playground and find its movement and pickup logic. Amber Ruins checks tile coordinates to decide whether you can enter a cell. When you collect a relic, it hides the sprite, plays a sound and updates the HUD. Follow one of those actions from the code to what you see on screen.

Use the API reference when you want to add a sprite, import a Tiled map, or draw a HUD with ScreenUI.

If you get stuck

The canvas is blank
Check the browser console for a failed import. Confirm that the element ID matches containerId and that the element has a height.
The explorer stays still
Focus the playable example. In your own code, check that fixedUpdate belongs to the engine callbacks and that you use ArrowRight, with that capitalisation.
The relic never disappears
Check both objects’ transform.position values. Compare the distance to the sum of the radii, and clear your reference once you destroy the relic.
